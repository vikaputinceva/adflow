# AdFlow

Система планирования и управления рекламными кампаниями малого бизнеса.
Учебный проект по ТЗ, сделан на Laravel 12 (PHP 8.2+) и SQLite.

## Что умеет

- вход по email и паролю, восстановление пароля по email
- три роли: администратор, менеджер, исполнитель (дизайнер / копирайтер)
- входящие заявки и превращение заявки в рекламную кампанию
- реестр кампаний, статусы, материалы кампании
- задачи со сроками, уведомления о близких и просроченных сроках
- финансы: бюджет, расход, выручка, уведомления о лимите бюджета
- отчёты: ROI по кампаниям и площадкам, KPI по задачам
- создание пользователей администратором

## Права ролей

| Раздел | Администратор | Менеджер | Исполнитель |
|---|---|---|---|
| Главная, кампании, заявки, финансы, отчёты | да | да | нет |
| Задачи (ставить и удалять) | да | да | нет |
| Задачи (смотреть и отмечать свои) | да | да | да |
| Пользователи | да | нет | нет |

## Запуск

```
composer install
copy .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

Если база SQLite, перед миграцией создайте пустой файл `database/database.sqlite`.
Для XAMPP можно указать в `.env` MySQL (`DB_CONNECTION=mysql`, имя базы, `root` без пароля).

## Восстановление пароля

Письма пишутся в лог (`MAIL_MAILER=log`), ссылку для сброса можно взять из `storage/logs/laravel.log`.
Для настоящей отправки укажите SMTP в `.env`.
